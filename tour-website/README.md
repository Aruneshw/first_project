# Wanderly — Tour Website

A modern, responsive tour and travel landing page built with pure HTML and CSS.

## Features

- Responsive mobile-first layout
- Hero travel section
- Destination cards
- Tour package pricing
- Call-to-action booking section
- Modern typography, spacing and animations-ready structure
- External destination photography via Unsplash

## Project Structure

```text
tour-website/
├── index.html
├── style.css
└── README.md
```

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.

## GitHub Pages

This project is static and can be deployed with GitHub Pages. In the repository, open **Settings → Pages**, choose the `main` branch and the `/tour-website` folder when the Pages configuration supports a folder source. If your Pages configuration only supports the repository root, move the contents of `tour-website/` to the root and select `main`.
